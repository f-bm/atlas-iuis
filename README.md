# Atlas IUIS 2024 — Erreurs Innées de l'Immunité (IEI)

Protocole de révision systématique des **555 IEI monogéniques et 17 phénocopies** de la classification **IUIS 2024** (*J Hum Immun* 2025, PMID: 41608114).

- **Application interactive** : https://f-bm.github.io/atlas-iuis/
- **Automatisation quotidienne** : `.github/workflows/atlas-iuis-daily.yml` (07h00 UTC chaque matin → Gemini Deep Research → Notion `Maladies IUIS 2024` + Quiz hebdomadaire)
- **Fiches générées** : dossier `fiches/`
